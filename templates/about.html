How It's Built

Every calculator is a self-contained Python module that declares which subject and sub-section it belongs to, supported by carefully verified reference values and automated testing. The home page, section pages, search index, and this count all read from one registry. All formulas are transparent and fully documented. We do not track or store user inputs; all calculations are performed in real time and remain private.
